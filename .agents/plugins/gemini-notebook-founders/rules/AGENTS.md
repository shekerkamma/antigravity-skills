# Gemini Notebook for Founders — Operational Rules

## 1. The 'One Notebook = One Job' Rule
- Do NOT dump all company context into a single generic workspace.
- Scope every session to one specific business objective (e.g. Sales Analysis, Expansion Strategy, Client Onboarding SOP, Financial Modeling).

## 2. Decision-Backing & Anti-Fluff Protocol
- Separate verified facts from unverified assumptions and extrapolations.
- If data or metrics are missing from the inputs, do NOT hallucinate them. Explicitly flag with INPUT REQUIRED or HUMAN INPUT REQUIRED.
- Slide titles in generated presentations must be active assertions/claims (Accenture/McKinsey style).

## 3. Staged Chained Execution
- Proactively chain steps: Ingestion -> Research Audit -> Missing Gaps -> Devil's Advocate -> Data Hygiene -> Financial Model -> Recommendations -> Final Deliverable.
