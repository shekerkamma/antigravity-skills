# Full Project Workflow — Staged Execution Runner

Use this skill when you have a significant strategic or operational initiative and want to ensure every analytical gate is satisfied before generating final deliverables.

## Staged Execution Protocol (Do NOT Skip Ahead)

Run each step sequentially, confirming output quality at each checkpoint:

- **Step 1: Review Current Sources** (
esearch-auditor)
  Map baseline facts, existing assumptions, and contradictions.
- **Step 2: Identify Missing Information** (missing-research-finder)
  Isolate Critical, Important, and Nice-to-Have knowledge gaps.
- **Step 3: Research Important Gaps**
  Perform deep web search, doc lookup, or data gathering on critical unknowns.
- **Step 4: Challenge Current Beliefs** (devils-advocate)
  Construct the strongest counter-hypothesis and pre-mortem failure analysis.
- **Step 5: Analyze Internal & Financial Data** (usiness-data-analysis / xcel-model-generator)
  Validate data hygiene, calculate unit metrics, and model scenarios.
- **Step 6: Develop Synthesis & Conclusion**
  Compare options and solidify the strategic decision.
- **Step 7: Create Action Recommendations** (xecutive-report)
  Draft concrete action items with evidence, owner, metrics, and risks.
- **Step 8: Generate Final Deliverables**
  Compile PPTX presentations (powerpoint-builder), Excel financial models, SOPs (sop-builder), or briefing memos.
